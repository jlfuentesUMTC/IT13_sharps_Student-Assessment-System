# Team Agreement

## Project
Student Assessment System with Item Analysis (IT 13 C# Final Project)

## Reminders for Everyone
- Code must be original. Plagiarism means project failure.
- Every member must contribute. The commit history will be checked.
- Commit regularly, not one big upload at the end.
- The app must not crash.
- Item analysis needs at least 30 students of data.
- Most points: Item Analysis (25%), OOP and Design Patterns (20%),
  Test Creation and Administration (15%), Statistical Accuracy (15%).
  The UI is only 5%.

## Working Rules
- Everyone commits under their own GitHub account.
- Every member writes code in at least two areas (for example UI and
  database), so the commit history shows fair contribution.
- Every pull request gets one reviewer.
- Everyone must be able to explain their own code.
