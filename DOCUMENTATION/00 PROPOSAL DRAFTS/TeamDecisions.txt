## Statistics Rules
- Difficulty (P) = correct / total
  - Easy: P > 0.75
  - Average: 0.25 to 0.75
  - Difficult: P < 0.25
- Upper and lower groups: top 27% and bottom 27% by total score
- Discrimination (D) = upper correct / n - lower correct / n
  - 0.40 and up: very good
  - 0.30 to 0.39: good
  - 0.20 to 0.29: marginal
  - below 0.20: poor
- Standard deviation: ____ (population or sample, pick one)
- Zero responses: return "no data", never crash
- Fewer than 30 students: show a warning

## Coding Rules
- Parameterized SQL only, never build queries by joining strings
- Handle all errors with a friendly message and a log file
- Naming: PascalCase for classes and methods, camelCase for variables
- One class per file
